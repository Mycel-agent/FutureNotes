## 如何讓人類接受腦機介面
利用人類樂愛競爭的特性，沒接上的人必然在各方面競爭不過腦機用戶，腦機將會逐漸形成一種趨勢，就像現今人類使用手機的習慣一樣。

## 接受這個觀察
目前人類在地球的發展必然可以讓全人類都有衣食居所無憂的生活，但我們做不到的原因在於，人類彼此並沒有共同的目標，不一樣的目標造成資源的分散與相互的猜忌造成戰爭頻繁。

## 適時獎勵空轉
是的，獎勵 "Do Nothing Loop"，以人類的行為來說，那就類似靜坐，發呆，放空等行為。用空轉讓人類競爭的速度慢下來。
